This directory should contain Z-machine game files (.z3, .z5, .z8, etc.) that you want to run with ZXZVM.

Popular Z-machine games that should work include:

- Zork I (zork1.z5)
- Zork II (zork2.z5) 
- Zork III (zork3.z5)
- Hitchhiker's Guide to the Galaxy (hhgg.z3)
- Planetfall (planetfall.z3)
- And many other Infocom classics

You can find many free Interactive Fiction games at:
- The Interactive Fiction Archive (https://ifarchive.org/)
- The Interactive Fiction Database (https://ifdb.org/)

To use:
1. Copy your .z5/.z3/.z8 game files to this directory
2. Run ZXZVM from BASIC: RUN "ZXZVM"
3. Enter the filename when prompted (e.g., "zork1.z5" or just "zork1")
